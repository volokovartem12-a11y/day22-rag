# День 22. Первый RAG-запрос

Агент с двумя режимами — **с RAG** и **без RAG** — и сравнение качества ответов
на 10 контрольных вопросах по базе документов.

## Как работает RAG-запрос

```
вопрос ──► retrieve()      поиск 4 релевантных чанков в индексе дня 21
       ──► build_prompt()  чанки с номерами [1]…[4] + вопрос → один промпт
       ──► llm.chat()      запрос к модели: «отвечай только по контексту, ставь ссылки [n]»
       ──► ответ со ссылками → cited_sources() определяет, на какие файлы модель сослалась
```

Вся цепочка — функция `ask_rag()` в `rag.py`. Режим без RAG — `ask_plain()`:
тот же вопрос той же модели, но без контекста.

**База:** проекты челленджа, дни 9–21 — 51 документ (README и код), ≈ 141 страница.
Индекс — из дня 21: стратегия `structure`, эмбеддинги `text-embedding-3-small` через
AITunnel. При первом запуске индекс собирается автоматически.

## Как оценивается качество

| Метрика | Что значит |
|---|---|
| Доля фактов | сколько обязательных фактов есть в ответе |
| Статус | **верно** (все факты) · **частично** · **честно не знает** (модель признала, что не знает) · **неверно** (уверенный ответ без нужных фактов) |
| Источник найден | поиск нашёл нужный файл среди 4 чанков (только RAG) |
| Источник процитирован | модель сослалась `[n]` на фрагмент из нужного файла (только RAG) |
| Токены | цена ответа: RAG дороже на входе из-за контекста |

Статус «честно не знает» отделён от «неверно» специально: для модели без RAG
признать незнание — хорошее поведение, а уверенно выдумать — плохое.

Результат — `output/rag_comparison.md`: сводная таблица, таблица по вопросам и
**полные ответы обоих режимов** с найденными и процитированными источниками.

## Проверено до живого запуска

- поиск на локальных эмбеддингах нашёл нужный источник для 7 из 8 вопросов по проектам;
  промах — вопрос 3: лексический поиск не связывает «слои» и «слоя». Поэтому основной
  режим — семантические эмбеддинги AITunnel (в дне 21 они нашли нужный файл для всех 15 вопросов);
- вся цепочка оценки на макете модели: статусы, разбор ссылок `[1]`, `[2, 3]`,
  игнорирование ссылок на несуществующие фрагменты, отчёт, режимы агента.

## Запуск (PowerShell)

```powershell
cd "путь\до\day22-rag"
Unblock-File .\run.ps1
.\run.ps1                                               # 10 вопросов: без RAG vs с RAG
.\run.ps1 -Mode ask -Query "Какие слои памяти в дне 11?"   # один вопрос, два ответа
.\run.ps1 -Mode chat                                    # диалог
```

Модель по умолчанию — `gpt-5.6-luna`; другую можно указать: `-Model gpt-4o-mini`.
