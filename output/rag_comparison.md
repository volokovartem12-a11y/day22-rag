### 10. Что такое function calling у языковых моделей?

**Ожидание:** Модель получает описания функций с JSON Schema параметров и вместо текста может вернуть имя функции и аргументы; приложение выполняет функцию и возвращает результат модели.  
**Ожидаемые источники:** не обязательны

**Без RAG** — верно, факты 100%

> **Function calling** — это механизм, при котором языковая модель не выполняет функцию сама, а формирует структурированный запрос к заранее описанной функции или API.
> 
> Как это работает:
> 
> 1. Разработчик описывает доступные функции: их названия, параметры и типы данных.
> 2. Модель анализирует запрос пользователя.
> 3. Если нужно действие извне, модель возвращает вызов функции с аргументами в структурированном виде, например JSON.
> 4. Программа выполняет функцию.
> 5. Результат передаётся модели, и она формирует ответ пользователю.
> 
> Пример:
> 
> Пользователь: «Какая погода в Москве?»
> 
> Модель может запросить:
> 
> ```json
> {
>   "name": "get_weather",
>   "arguments": {
>     "city": "Москва"
>   }
> }
